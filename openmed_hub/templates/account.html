An independent installation is a site that registered a node key and completed the verification handshake. From the machine that will run your node:

pip install "openmed[hub]"        # or: pip install -e ".[hub]" from a checkout
openmed login --hub {{ settings.hub_url }} --token <your token>
openmed node keygen                 # writes ~/.openmed/node.key
openmed node register               # posts the public key, signs the challenge
