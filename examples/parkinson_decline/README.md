# Example: securing collaborative Parkinson's prognosis

This example is the motivating use case for TrustFed. Six simulated
movement-disorder centers jointly improve a **rapid cognitive/motor decline**
classifier without sharing patient records. The focus is the **integrity** of
that collaboration: TrustFed keeps the shared model correct — and keeps
unapproved code out — when some centers are compromised or malicious.

## Run it

```bash
python examples/parkinson_decline/run_demo.py
```

## What it shows

The script sweeps eight scenarios and prints a comparison table:

- **Baseline** (no attack, FedAvg) establishes the clean AUC (~0.86).
- **Under poisoning** (`scaling` and `sign_flip` attacks from 2 of 6 sites),
  naive **FedAvg** degrades badly — sign-flip drives AUC below 0.5.
- **Robust aggregation** (coordinate median, trimmed mean, Multi-Krum) holds AUC
  at the clean baseline.
- **Attestation ON** rejects the 2 sites running tampered code *before*
  aggregation (watch the `rejected` column), so even FedAvg stays clean.

## The data is synthetic

Features imitate the real prognostic setting — regional structural-MRI atrophy
rates plus baseline clinical scores (age, UPDRS-III, MoCA, REM-sleep behavior,
hyposmia, disease duration) — but every value is randomly generated by
[`trustfed/data/synthetic.py`](../../trustfed/data/synthetic.py). **No patient
data is used.** To run on a real cohort, see [`docs/DATA.md`](../../docs/DATA.md).

## Tune it

Edit the constants at the top of `run_demo.py` (`ROUNDS`, `LOCAL_EPOCHS`) or the
`scenarios` list to try other aggregators (`fedavg`, `median`, `trimmed_mean`,
`krum`, `multi_krum`) and attacks (`none`, `gaussian`, `sign_flip`, `scaling`).
